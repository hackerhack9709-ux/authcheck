Exhibit U · Why teams pick it

Explainable beats confident.

Every other detector gives you a number and asks you to trust it. Editors cannot publish "the model said 87% fake". They need the reasoning — and so does your audit trail.

01 / Explainable

Reasons, not just a score

Every verdict ships with the signals behind it: a broken C2PA hash, a stripped EXIF block, an ELA hot-spot, forward-bait language. Reviewers can see why, and disagree with it.

02 / Multi-modal

Image, audio, video and text

One API and one key for all four. Photos, voice notes, clips and written claims — the same score shape, the same header, the same reasons.

03 / Private by design

Zero upload retention

Analysis happens per request and the file is not stored. Nothing to leak, nothing to subpoena, nothing sitting in a bucket.

04 / Transparent

Open standards underneath

Built on C2PA Content Credentials and the Google Fact Check Tools, so the output speaks a language your policy team already recognises.

05 / Honest

It never claims to prove truth

A missing credential is not proof of faking, and a reference hit is not proof of truth. The payload says so out loud. That restraint is the point.

06 / Cheap to start

Exhibit W · The API

Four endpoints. One header. Five minutes.

Send your key as an X-API-Key header. Every metered response also carries X-RateLimit-Tier, X-RateLimit-Limit and X-RateLimit-Remaining.

# check a claim
curl -H "X-API-Key: ac_your_key" \
     --data-urlencode "text=Drinking hot water cures every disease" \
     https://authcheck-u1e8.onrender.com/api/check-text

# check an image
curl -H "X-API-Key: ac_your_key" \
     -F "file=@photo.jpg" \
     https://authcheck-u1e8.onrender.com/api/analyze-image

# audio and video follow the same shape
curl -H "X-API-Key: ac_your_key" -F "file=@voice.wav" /api/analyze-audio
curl -H "X-API-Key: ac_your_key" -F "file=@clip.mp4"  /api/analyze-video

# how much quota is left?
curl -H "X-API-Key: ac_your_key" /api/usage
import requests

BASE = "https://authcheck-u1e8.onrender.com"
HEAD = {"X-API-Key": "ac_your_key"}

# a written claim
r = requests.post(f"{BASE}/api/check-text", headers=HEAD,
                  data={"text": "Drinking hot water cures every disease"})
d = r.json()
print(d["score"], d["verdict"])      # 66 caution
for f in d["flags"]: print(f["text"])  # every reason

# a photo
with open("photo.jpg", "rb") as fh:
    r = requests.post(f"{BASE}/api/analyze-image", headers=HEAD,
                      files={"file": fh})
print(r.json()["verdict"])
const BASE = "https://authcheck-u1e8.onrender.com";
const KEY  = "ac_your_key";

// a written claim
const body = new URLSearchParams({
  text: "Drinking hot water cures every disease"
});
const res = await fetch(`${BASE}/api/check-text`, {
  method: "POST",
  headers: { "X-API-Key": KEY },
  body
});
const d = await res.json();
console.log(d.score, d.verdict, d.flags);
